# 剑修构筑 · 回合制战斗（数据版 v2）

> 每回合 1 行动次数（`AT`）。首回合获得 2 `AP`，之后每回合回复 1 `AP`。技能按费用结算。主动行为 QTE 不额外回复 `AP`。
> 装配：**4 个技能 + 1 个神通**；神通目前只实装 `开天`。

## 一、资源

| 资源 | 记号 | 范围 | 说明 |
|---|---|---|---|
| 行动次数 | `AT` | 0-2 | 每回合 1-2；标「不消耗行动」的技能不占用 |
| 行动力 | `AP` | 0-9 | 首回合 +2，之后每回合 +1，用于行动消耗 |
| 神识 | `X` | 1-30 | 局外成长，决定剑势上限 |
| 剑势值 | `F` | 0-`L` | 常规 1-`L`（1-5 档）；`0` 仅见于无我，受击格挡失败剑势值-1 |
| 剑势上限 | `L` | 5 | 剑势上限值 |
| 剑势倍率 | `M(F)` | 1.0-2.0 | 按剑势档位结算；无我视为 5 档 |
| 留痕值 | `Y(F)` | 25-10,000 | 飞剑类技能按释放时的剑势档取值 |
| 剑意 | `S` | 0-40 | 开天门槛 + 增伤 |
| 剑意留痕 | `T` | 0-∞ | 战斗内累计，开天清零 |

```text
L = min(5, ⌈X / 5⌉)
N(S) = 1 + 0.025S，S 上限 40 时 ×2.0
剑势初始：每场战斗开始 F = 1
```

### 剑势档位规则

- 常规状态剑势只有 **1-5 档**，不再存在 0 档。
- `0` 档只能通过 `无我` 进入，且在无我期间无法被增加。
- 无我的剑势**记作 0，但视为 5 档**：倍率、门槛判定、`Y` 取值一律按 `F = 5` 结算。
- **受击格挡失败时剑势 `-1`，但下限为 1**：在 `F = 1` 时格挡失败剑势仍为 1，**永远不会掉到 0**。
- 因此 `F = 0` 是无我的专属状态，没有任何途径能靠挨打刷出来。
- 剑势跨场不继承，每场重置为 1。

```text
M(F)：F=0(无我) 2.0 / F1 1.0 / F2 1.15 / F3 1.3 / F4 1.5 / F5 2.0
无我结算：M = 2.0（取 F=0 档，与 F=5 同档），门槛判定与 Y 取值按 F=5
```

## 三、通用伤害公式

```text
伤害 = 攻击 × 技能系数 D × M(F) × N(S)
飞剑类额外：T += Y(F_释放前)
```

`D` 为每个技能的基础倍率（本次新增，见下表）。技能表中的 `D` 为占位值，可继续调。

## 四、剑意与留痕来源

### 剑意 `S`

| 来源 | 剑意 |
|---|---|
| 我方实际受到攻击 | +1（同一敌方行动最多 +1） |
| 普攻 | +1 |
| 寒光（回 `AP` 类） | +1 |
| 剑气 | +1 |
| 摧城 / 无量连斩（加剑势类） | +1 |
| 凝剑（加剑势但不给剑意） | +0 |
| 御剑 / 贯虹 / 寰宇千锋（御剑技） | +0 |
| 无极剑域 / 剑心无我 | +0 |

**规则**：加剑势类攻击、回 `AP` 类攻击、普攻都可涨剑意；飞剑伤害类技能降剑势（`剑势 -1`），涨留痕但不涨剑意。

### 留痕 `T`

留痕只来自飞剑伤害类技能，按**释放时（扣减前）的剑势档**取值：

```text
T += Y(F_释放前)        // 御剑 / 贯虹 / 寰宇千锋 通用
```

因此在高剑势释放飞剑可换到高额留痕，形成「堆剑势 → 倾泻换留痕」的循环。开天为 `T = 0`，即一次清空全部积累。

## 六、技能详规

### 普攻

```text
AP：0 费，AP +1
伤害 = 攻击 × 1.0 × M(F) × N(S)
剑意 +1
```

- 常驻基础行动，不占技能位。0 费即净赚 1 `AP`，是「以行动换行动力」的核心。

### 凝剑

```text
AP：2 费
剑势 < 3  → 升至 3
剑势 ≥ 3  → +1（不超过 L）
剑意 +0
```

- 唯一不吃剑意的加剑势技能：它只负责把剑势垫高，供后续御剑类技能兑现倍率。
- 无我：剑势增加被禁止，两个分支均失效，仍照常付费。

### 寒光

```text
AP：1 费，AP +3，上限 9 封顶
伤害 = 攻击 × 1.0 × M(F) × N(S)
剑意 +1
```

- 唯一回 `AP` 手段，同时带一份 `D = 1.0` 的剑气伤害，1 费换 3 `AP` + 一次攻击 + 1 剑意，是全技能池性价比最高的一手。

### 摧城

```text
AP：3 费
伤害 = 攻击 × 1.4 × M(F) × N(S)
剑势 < 3  → 升至 3
剑势 ≥ 3  → +1（不超过 L）
剑意 +1
```

- 与凝剑同一条剑势曲线，但贵 1 `AP`、多 40% 伤害、多 1 剑意。剑势已 ≥3 时用摧城，剑势不足时用凝剑垫。
- 无我：剑势分支失效，伤害按 `M = 2.0×` 结算（等同 `F = 5`）。

### 无极剑域

```text
AP：5 费
门槛：剑势 = 5 时可用
效果：本回合「御剑技」费用 −1、伤害 +20%，且御剑技不消耗剑势
```

- 覆盖全部**御剑技**（御剑 / 贯虹 / 寰宇千锋），不只是御剑。
- 「不消耗剑势」是这张牌真正的价值：常态御剑技要 `剑势 -1`，域内连发可以把 `F = 5` 当成不掉的弹药池，`Y(5) = 10,000` 每发都能吃到。
- `5` 费意味着它和输出抢同一个 `AP` 池：单回合满 `9 AP` 的极端口径是「域 5 + 御剑 4 × 1」，**4 发 = 40,000 留痕**。
- `+20%` 与减费、免降势三项可叠加，域内单发上限（寰宇千锋 `F=5` 满血）从 `9.0×` 抬到 `10.8×`。
- 本身不加剑意、不降剑势、不造成伤害。
- 无我：无我时 `F = 0` 视为 `F = 5`，故**门槛通过、可正常使用**。但无我本来就不掉剑势，「不消耗剑势」自动成立，实际收益是减费 + `+20%`。

### 御剑

```text
AP：2 费；不消耗行动（不占用 AT）
门槛：剑势 ≥ 3
伤害 = 攻击 × 1.6 × M(F) × N(S)
剑势 −1；剑意 +0；留痕 += Y(剑势释放前)
```

- 御剑技一律 `剑势 ≥ 3` 才能使用，域内虽然不降剑势，但门槛依然要过。
- 无我：剑势记作 0 但视为 `F = 5`，门槛通过、`M = 2.0×`、留痕 `Y(5) = 10,000`，全部按满档兑现。
- 代价：剑势本就是 0，`剑势 −1` 无事发生，所以无我是**唯一能无限连发御剑技的形态**——只要 `AP` 够。

### 剑气

```text
AP：3 费；不消耗行动（不占用 AT）
伤害 = 攻击 × 1.2 × M(F) × N(S)
剑意 +1
```

- 剑技而非御剑技：不消耗剑势、不产留痕、不吃无极剑域减费，纯粹为剑意与不占行动的高频输出。
- 剑意唯一的「无消耗」来源：不占行动、不吃剑势门槛也不产留痕，是 `S` 推进的主引擎。

### 贯虹

```text
AP：4 费
伤害 = 攻击 × 2.0 × M(F) × N(S)
增伤：自身 HP 处于残血时增伤
剑势 −1；剑意 +0；留痕 += Y(剑势释放前)
```

- 「自身残血增伤」取**线性**：HP 从 100% 降到 30% 时伤害线性递增，30% 及以下封顶 `×1.5`。

```text
残血倍率 = 1.0 + 0.5 × (1 - HP%) / 0.7    (HP% > 30%)
         = 1.5                             (HP% ≤ 30%)
```

| HP | 100% | 90% | 80% | 65% | 50% | 30% 及以下 |
|---|---:|---:|---:|---:|---:|---:|
| 倍率 | ×1.0 | ×1.07 | ×1.14 | ×1.25 | ×1.36 | ×1.5 |

- 与剑心无我联动：无我把 HP 置 1，必定吃满 `×1.5`，`2.0 × 1.5 = 3.0` 基础系数。注意无我的 `M` 只有 `2.0×`，所以贯虹残血峰值与 `F = 5` 时的寰宇千锋同为 `9.0×`，并不天然领先。

### 寰宇千锋

```text
AP：6 费
伤害 = 攻击 × 3.0 × M(F) × N(S)
剑势 −1；剑意 +0；留痕 += Y(剑势释放前)
```

- 御剑技中系数最高的一发，单体收益超过贯虹满血状态。
- 无我：视为 `F = 5`，可用，吃 `M = 2.0×` 与 `Y(5) = 10,000`。

### 无量连斩

```text
AP：7 费
伤害 = 攻击 × 2.4 × M(F) × N(S)
剑势 +2（不超过 L）
剑意 +1
```

- 唯一能 `+2` 剑势的技能，是把 `F` 从 3 顶到 5 的关键一跳，也是冲 `S ≥ 20` 开天的主引擎。
- `7` 费需要存力：`AP` 首回合 2 点，之后每回合只回复 1 点；前期需要靠普攻或寒光的净回复跨回合积攒。
- 无我：剑势增加被禁止，分支失效，伤害按 `M = 2.0×` 结算（等同 `F = 5`）。

### 剑心无我

```text
AP：6 费
门槛：剑势 = 5 时可用
触发：本回合内受击将进入濒死（HP 归零）时
    → HP 置 1，获得「无我」，AP 回满（→ 9），技能消耗
每场限一次（触发即消耗）
```

无我持续至战斗结束，无解除手段。

## 七、无我状态

无我是「剑势 0 档」的唯一来源，且**不可通过格挡失败刷出**（格挡失败下限为 1）。

其定位是：**剑势记作 0 但视为 5 档**，因此所有门槛技能照常可用，而倍率 `M(0) = 2.0×` 与真正的满剑势 `F = 5` 同档——**无我不给倍率加成，只给「门槛豁免 + 弹药无限 + 留痕满额」**。

代价是三条：1 HP 且不可回复、不可逆、以及剑势永久停在 0（`剑势 +` 全部失效）。

| 规则 | 说明 |
|---|---|
| 无法回复 | 不能通过任何技能或道具恢复 `HP` |
| 剑势记作 0 | 面板显示 `F = 0`，但**视为 `F = 5`** |
| 视为 5 档 | 门槛判定、`M` 取值、`Y` 取值全部按 `F = 5` |
| 剑势不可增加 | 凝剑 / 摧城 / 无量连斩 的加剑势分支全部失效 |
| 倍率 2.0× | `M = M(0) = 2.0×`，与 `F = 5` **同档**，无额外加成 |
| 御剑技**可用** | 视为 `F = 5` 故 `剑势 ≥ 3` 门槛通过；且剑势本就是 0，`剑势 −1` 无事发生 |
| 无极剑域**可用** | 门槛通过；「不消耗剑势」在无我下自动成立，净收益为减费 + `+20%` |
| 留痕照常 | 御剑技按 `Y(5) = 10,000` 累计，与满剑势等同 |
| 凝剑失去意义 | 无剑意、无剑势增长，纯亏 2 `AP` |
| 持续 | 至战斗结束，无解除 |

**无我下的技能可用性**：除**凝剑**（无剑意、无剑势增长）外全部可用——普攻、寒光、摧城、无极剑域、御剑、剑气、贯虹、寰宇千锋、无量连斩、开天。

### 无我带来的三个结构性红利

**1. 御剑技可无限连发。** 常态下每发御剑要 `剑势 −1`，`F = 5` 只够打 3 发就跌到门槛外（累计仅 13,000 留痕）；无我里剑势不降，等于一个**不掉的弹药池**。配合无极剑域减费（2 费 → 1 费），`9 AP` 可打出「域 5 + 御剑 4 × 1」，**单回合 40,000 留痕**。

**2. 留痕不再受剑势消耗限制。** 常态下每回合最多打 4 发（40,000），三档要攒 3 个回合；无我里剑势不降，攒速不受门槛打断。

**3. 贯虹吃到满血增伤。** 1 HP 时 `×1.5` 拿满，`2.0 × 1.5 = 3.0` 基础系数与寰宇千锋持平。

倍率既然与满剑势同档，无我的定位就从「用血换伤害」变成了**「用血换续航与操作自由」**：单发上限不变，但可以把所有御剑技在单回合内打完，并且不必再操心剑势掉出门槛。真正的风险只在于挨那一下时能不能活下来。
