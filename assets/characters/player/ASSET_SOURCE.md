## Notes

- The model is a low-poly humanoid placeholder suitable for an early
  cultivation RPG protagonist.
- The current file is self-contained. The `textures/` folder is reserved for
  future external base-color, normal, roughness, or metallic maps.
- CC0 allows commercial use and does not require attribution. This source note
  is kept for project tracking.
- The current combat code does not automatically play imported animations.
  Check the GLB in Godot before relying on Idle, Attack, Hit, or Death clips.
